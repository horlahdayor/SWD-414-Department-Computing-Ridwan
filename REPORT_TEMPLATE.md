## 2. Project setup

## 3. Recording changes

## 4. Branching and merging
I created a separate branch named `feature/contact-us` to work on the Contact Us page. After recording the changes in a commit, I switched back to the main branch and merged the feature branch. I inspected the branch and commit history using `git log --oneline --graph --all`.

## 5. Using GitHub and updating the project
I created a remote GitHub repository, connected it to my local repository, and pushed the project commits. I made a further website update, committed it locally, and pushed the new commit to GitHub.

## 6. Difference between commit and push
A commit records staged changes in the local repository. A push sends local commits to the remote repository on GitHub. Therefore, a commit by itself does not automatically upload changes to GitHub.
