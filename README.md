# Department of Computing Website — SWD414

A responsive, four-page demonstration website created for the SWD414 assignment on Version Control, Git and GitHub.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `programmes.html` — Programmes
- `contact.html` — Contact Us

## Run the website
Open `index.html` in a web browser. No package installation is required.

## Important customisation
This is a sample student assignment website. Replace generic institution details, sample programme descriptions, and `computing@example.edu` with verified information before presenting it as an official site. The contact form is a front-end demonstration and does not send messages to a server.

## Suggested Git workflow
See `GIT_COMMANDS.md` for the commands used to demonstrate repository setup, commits, branching, merging, and pushing to GitHub.
